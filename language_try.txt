<include:"Resiris.module"> ## includes the general Resiris module

## We have a module named ResirisGameEngine, but it is only for games.
## The main Resiris.module contains the general system elements.
## Include both modules when the program needs game and system features.

v player = Resiris.module.player ## sets the player variant to the player object
v input = Resiris.module.input.get_input
v input_window = ResirisGameEngine.window

v up_window_input_button = ResirisGameEngine.editable_button
v down_window_input_button = ResirisGameEngine.editable_button
v right_window_input_button = ResirisGameEngine.editable_button
v left_window_input_button = ResirisGameEngine.editable_button

fn start(): ## Runs this function once when the program starts.
    set_input_setting()
    draw_player()

fn set_input_setting():
    input_window.show_window() ##shows the given window
    input_window.title = "Input Window" ##sets window title

    ##up
    up_window_input_button.init() ##instantiates the editable button
    up_window_input_button.text = "Press a button to set the 'up' direction" ##sets button title to the given title
    input.up = await input.wait_for_next_press() ## waits for a valid input except MODE
    up_window_input_button.input = input.up ## assigns the selected input to the button

    ##down
    down_window_input_button.init()
    down_window_input_button.text = "Press a button to set the 'down' direction"
    input.down = await input.wait_for_next_press() 
    down_window_input_button.input = input.down

    ##right
    right_window_input_button.init()
    right_window_input_button.text = "Press a button to set the 'right' direction"
    input.right = await input.wait_for_next_press() 
    right_window_input_button.input = input.right

    ##left
    left_window_input_button.init()
    left_window_input_button.text = "Press a button to set the 'left' direction"
    input.left = await input.wait_for_next_press() 
    left_window_input_button.input = input.left

fn draw_player():
    player.init() ## initializes the player
    player.position = Vector2(1, 1) ## origin is at 0, 0

fn process(delta): ##runs on every frame after start
    if input.just_pressed == input.up:
        player.position.y += 1
    elif input.just_pressed == input.down:
        player.position.y -= 1
    elif input.just_pressed == input.right:
        player.position.x += 1
    elif input.just_pressed == input.left:
        player.position.x -= 1
    else:
        return

Resiris language elements and defined words
########################################################################

## The basic keywords of the language

include:
    Includes another module or file in the program.
    Example: <include:"Resiris.module">

v:
    Defines a variable.
    Example: v number1
c:
    Defines a constant.
    Its value and value type cannot be changed after definition.
fn:
    Defines a function. A function is a named block of code
    that can be called later.
    Example: fn start():

start():
    A function that runs once when the program starts.

process(delta):
    A function that runs on every frame while the game is running.
    delta stores the time passed since the previous frame.

await:
    Waits for an event or result before continuing the function.
    Example: input.up = await input.wait_for_next_press()

if:
    Checks a condition. Its block runs only when the condition is true.

elif:
    Checks another condition when the previous if condition was false.

else:
    The counterpart of if. It runs when the if condition is false.

match:
    Compares a value with multiple possible options.
    The code in the matching branch is executed.

return:
    Stops the current function and optionally returns a value.

=:
    Assigns a value to a variable.

+=:
    Adds a value to a variable.

-=:
    Subtracts a value from a variable.

*=:
    Multiplies a variable by a value.

/=:
    Divides a variable by a value.

pass:
    Performs no operation. It is used as a placeholder for an empty block.
    It does not stop the function and does not ignore code after the block.

## Defined Resiris and ResirisGameEngine elements

Resiris.module:
    The main Resiris module, containing the basic system elements.

ResirisGameEngine:
    The module containing the game-related systems.

ResirisModule:
    The type used by a variant that references a Resiris module function.

player:
    The player object. After initialization, its position can be set
    with the position property.

input:
    The input system object. just_pressed represents the button
    that was just pressed during the current frame.

window:
    A window object that can be displayed and configured.

editable_button:
    A button to which the user can assign an input.

Vector2:
    A value that stores two-dimensional coordinates, such as Vector2(1, 1).

init():
    Initializes or creates an object.

show_window():
    Displays the window.

wait_for_next_press():
    Waits for the next user button press and returns the pressed button.

position:
    A property that stores an object's position.

title and text:
    Properties that store the displayed text of a window or button.

int:
    Stores a whole number.

float:
    Stores a number with a fractional part.

string:
    Stores text.

bool:
    Stores true or false.

str():
    Converts a value into text.

print:
    A callable variant assigned to the Resiris.print() module function.
    It can be called as print(value) after this declaration:
    v print : ResirisModule = Resiris.print()
    It is not a built-in keyword of the language.

## A line beginning with ## is a comment. The interpreter ignores the
## comment text after ## on that line.

## Indentation determines which block each line of code belongs to.
## The language structure is based on Godot/GDScript, but Resiris has
## its own keywords and objects that must be defined separately.

Resiris.base_button:
    Provides the base input button used by the calculator example.

Resiris.base_window_clear():
    Clears the base window before the calculator starts.

v print : ResirisModule = Resiris.print()
v test_value : int = 100
## print text:
print("Hello World")
## print value as text:
print(str(test_value))
## print value:
print(test_value)

If a variable has a name but no value or value type, it is an
"UnknownObject variant". It can receive a value in the future.
The first assigned value gives it a value type.

If a value type is declared, every assigned value must use that type.

c random_value : int = 1
random_value = "text" ## TypeError!

v asd1 : int = 1.1 ## TypeError!
c asd2 : int = 1.1 ## TypeError!
v asd3 : int ## Declared type, value can be assigned later.

## Common interpreter errors

UnknownVariableError:
    A variable was used before it was defined.

TypeError:
    A value has the wrong type.

ConstantAssignmentError:
    A new value was assigned to a constant.

MissingValueError:
    A variable was used before receiving a value.

SyntaxError:
    The code structure is invalid.
