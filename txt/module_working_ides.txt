1. A Resiry module is a library written and build for only the Resiris Programming Language.

2. To be able to use a module you have to include it into the .resy file, by typing " <include> ModuleName"

3. As the Runtime reads the .resy file, it will import the give modules from the "Modules" folder. Every module including has to happen on the top of the file!
So it has to look like this:"<include> ModuleName
                              <include> ModuleName2" or " <include> ModuleName , ModuleName2 "

4. If a module is not found then The runtime give an error:"{ModuleName} not found!" Error code:"MissingModule"

5. A module can have data and can give data like: int, float, string, bool, function.
A module cant have data like: UnknownObject, so every variant need to have a given value which cant change, so idealy use constans.

6. Modules will be written in C++.

7. The exact file format of the modules is currently unknown.

8. A module is a library/namespace, not a normal Resiris object.

9. The module can create its namespace after it is included, so the user does not have to create a variable for the module.

10. The data of a module should ideally be read once when the module is included, so later it can be used locally by the Runtime.

11. How to use a module:
"<include> ModuleName, ModuleName2

print_cmd(ModuleName.module_function_name(argument))

or

print_cmd(ModuleName.module_constans_value)"

12. Only int,float,bool,string can be argument! Otherwise gives error:"{given_argument} is not a usable modules argument!" Error code:"UnknownModuleArgument"

13. Module functions can return Resiris values.

14. Example:
<include> RSMath

v result float = RSMath.sqrt(25)

15. The "." is used to access functions and constants inside a module namespace.

16. The exact rules of the "." operator are not decided yet.
